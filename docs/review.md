# 0.5.2 审核与修复记录

2026-11-18，针对原项目 `feat/dsh-single-install` 分支开展三路子 agent 审核和交叉复审，然后拆分为本仓库。审核重点为卸载、插件共存和消息/问答边界。只把可复现的问题记为修复；通过测试不代表对未知缺陷作保证。

已修复的行为包括：

- 注册 URL 更新失败时保留旧传输归属，可再次恢复或清理。
- 注册互斥覆盖跨进程竞争与进程退出，保守处理旧文件锁；不抢其他活跃实例。
- 旧安装器的迁移标记只授权其实际拥有的入口，不按相似文件名接管外部 MCP。
- 注销某资源失败后仍尝试清理其余资源；失败项目可重试。
- 停用或删除 HTTP MCP 会话后，上传中的请求不能恢复会话或继续调用工具。
- 工具名冲突在修改 Codex 配置前失败并回滚；保留外部插件的原工具与路由。
- 工具列表查询不依赖 DSH 网关凭据初始化。
- 问答只接受仍有效的问题，校验回答端及可用的宿主来源，拒绝重复覆盖，并清理成功/失败/取消/超时的短期文件。
- 问答超时传入真实适配器的传输，取消正在进行的调用。
- DSH 发送不再先创建会话，避免目标在校验后被删时悄悄补建。
- Codex 空会话创建成功后若本地索引写入失败，错误保留新会话 ID，避免盲目重试。
- JSON/迁移正常错误路径清理暂存文件，保持原文件权限；强制中断的暂存残余由显式清理处理。
- 提供不输出密钥的离线 inspect/apply 清理，检查所有权并保留其他 profile、外部连接与共享历史。

验证覆盖默认隔离测试、真实 Codex 配置接口、DSH 官方工具注册器的重复名行为、标准发布包离线安装，以及真实 DSH 宿主内的安装/停用/重启/重复安装/卸载。具体执行结果记录在发布说明中；可选真实模型消息测试不属于默认测试套件。

仍有的产品边界：

- 强制结束宿主或离线卸载无法执行生命周期；使用离线清理处理失效注册。
- 正常停用保留可恢复的私密注册凭据；显式清理才删除它们。共享聊天历史、用户下载目录与宿主依赖缓存不自动清除。
- Codex MCP 配置加载、桌面登记和 DSH 插件应用方式随客户端版本变化；桌面名称未同步时返回未完成。
- 来源上下文用于归因，不是同 OS 用户之间的安全隔离；没有宿主来源的兼容调用不能验证具体回答会话。
- 两个客户端可在校验后自行移动或归档会话，宿主发送 API 未提供工程/归档状态的 compare-and-swap，桥不能保证跨进程原子锁定目标状态。
- 入队回执使用 `accepted: true`、`deliveryConfirmed: false`、`completed: false`，不表示对方已消费；尚无结构化收件箱、`peer_reply`、进程重启后的问答恢复或循环对话终止策略。
- 注册更新使用短期本机互斥；端口被其他程序占用时安全拒绝，不能保证任何主机环境均可注册。
